Your Turn — In Pairs

Work on paper. Your instructor says nothing until you ask. Flip each card when you're ready to check.

P1. Guest list of n names. Plain-language instructions to check whether “Dewi” is on it. How many steps in the worst case?
Check names one by one.

Worst case: Dewi is last — or absent — so n steps.
P2. Two guest lists of n names each — find any name that appears on both. Instructions + step count?
For each name on list 1, check all of list 2:

n × n = n² steps.
(Clever shortcuts? Explore them — don't shut them down.)
P3. A loop runs n times; inside it, something happens 3 times. Total steps?
3n steps.

Hold this answer — it starts tonight's big debate.
Bonus. Add 1 + 2 + … + 100 without adding one by one.

0:55 · Debrief

The Doubling Test

Your new intuition tool for the whole semester: double the input — what happens to the steps? Try it.

n = 5 names
A · n
5×2
B · n²
25×4
Double the input: Program A's work doubles (×2). Program B's work quadruples (×4). That difference never goes away — it only gets bigger.

The constants debate

P3 gave 3n. Is 3n in a “different league” than n when n is a million? Let them argue it out — then look at the chart:

The 3 just tilts the line — same shape, same league. For huge n, the shape matters; the constant doesn't.
Worst case: when searching an unsorted guest list, we plan for the unluckiest input — the name is last, or absent. That's the number we count.

Homework

  1. Trace. Hand-trace this snippet for the list [4, 7, 2, 9] with a variable table (columns: step, x, total):

  2. Count. Two short snippets — write the step count as a function of n (one linear with an inner constant, one nested).
